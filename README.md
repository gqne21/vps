搬瓦工对新账户有 30 天全额退款保证，这点比很多只给 7–14 天、甚至对 VPS 排除退款的主流商家宽松。但条款里有几个容易被忽略的地方，直接决定你能不能退成：

1. **30 天按账户注册时间算**，从首次购买起算。登录账户后访问退款自查页（refund.php）能直接看到自己是否符合条件。
2. **累计付款金额有上限**。条款历史上的口径是 $60–100、付款不超过 10 次。这意味着香港月付 $89.99 这类高端套餐，单笔就超了上限，**基本不满足退款条件**。想用退款权利试水，$49.99 的 KVM 或 $169.99 的 GIA-E 年付在限额内，香港和新加坡系列不在。
3. **退款是整账户全退**，不能只退一台机器。提交退款后账户下所有 VPS 立即终止，数据、快照、备份立即删除且不可恢复，退款后账户永久失去再次退款资格。所以退款前务必备份。
4. **绝对不要用 PayPal 争议（chargeback）来退款**。官方明确会因此暂停名下所有服务，并按 $40/小时、15 分钟起计收取处理费，付清才恢复。

正确的退款流程：备份数据 → 提交工单说明退款原因并声明数据已备份 → 收到自动回复后回复 "I agree" → 等原路退回。另外，IP 被封锁（包括被墙）会导致退款作废，所以开通当天就该测一下分配到的 IP 能不能用，别拖到第 29 天。
